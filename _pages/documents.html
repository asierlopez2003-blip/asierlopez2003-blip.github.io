The full written output of my degree projects and research placements, published as PDFs. Each entry below is a public file hosted with this site — there is nothing to request and no access restriction.

These PDFs are not tagged for accessibility, so they carry no reliable text layer for a screen reader or a reflowable text view. That is a property of how they were typeset upstream, not something that can be patched afterwards. What is offered instead is the summary below each title, which is the same text as the abstract in the document, and every document states its own page count and file size up front so you can decide before downloading.
